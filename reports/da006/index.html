DA006 — Dated filer-to-symbol map for DAG001

DA006Nov 4, 20262 min read

The map is accurate but incomplete, so the route does not yet qualify. On the seven cached quarter ends it names the right ticker for 88.1% of the listed universe on average, at least 84.1% in every window, against 90% and 85% required. When it names a listed ticker, that ticker is right 98.9% of the time. The shortfall is coverage: filings whose XBRL file name follows a filing agent's pattern rather than the ticker get no answer. That share is about 3% in 2016-2020 and rises to about 38% in late 2021. This is a feasibility check with no prices read. It is not a performance Batch.

Results

Criterion Result Required Pass

C8 acquisition 33 of 33 SEC files verified; corporate actions complete in 10 pages all yes

The prefix alone (R1) has recall 0.874 and precision 0.991, so chaining through Alpaca's 3,492 usable name changes adds only 0.7 points. In each gold window, 143 to 359 universe names have no ticker-form file name, and 115 to 150 get a wrong answer. Of the wrong answers, only 27 to 32 are another listed ticker. The rest are stale or invented mnemonics, such as LVIS for LEVI, ZIONS for ZION, WYN for TNL and TMB for CAG. Share-class roots also miss, for example GOOG for GOOGL and LILA for LILAK.

The historical pattern is the useful part. Before inline XBRL, almost every filer named its instance file by ticker. From 2019 onward, filing-agent names such as tm2412345 spread. So the map is strongest exactly where DAG001 needs new history, in 2016-2020, and weakest in 2021-2023.

Method and limits

The 33 FSDS files for 2015q4 to 2023q4 (3.05 GB) came from SEC with the owner's stored user agent. Alpaca corporate actions for 2016-01-01 to 2026-11-03 came in 10 pages: 3,719 name changes, 2,068 cash mergers, 3,228 stock mergers and 252 stock-and-cash mergers. All 43 attempts returned HTTP 200, within a reservation of 98. Raw bytes are outside Git under .research_tmp/da006. Only sub.txt was read, and no price, return or signal was touched. The gold truth is Massive's dated mapping on the DA001 liquid universe, which covers 2024-2026 only, so 2016-2023 accuracy is inferred, not measured. The historical counts include unlisted filers.

Next decision

This rule stops here, with no change after seeing the gold measure. The block is narrow and needs no new request: a filer with a non-ticker file name can borrow the ticker-form prefix of its own earlier filings. A follow-up rule that does this causally, using only filings accepted on or before the formation, is the next test. If that still fails, the remaining route is the paid Massive plan, which has dated ticker reference data.
