DA007 — Dated symbol map with a causal fallback

DA007Nov 4, 20262 min read

The dated filer-to-symbol map now qualifies as a development identity route for a 2016-2024 DAG001 replication. On the seven cached quarter ends it names the company's ticker for 91.7% of the listed universe on average, at least 87.3% in every window, with 99.3% precision. At least 91.6% of nonfinancial filers resolve at every quarter end from 2016 to 2024. No prices or returns were read, and no external request was made. This qualifies an input. It says nothing about the strategy.

DA006's rule used only each filing's own file-name prefix. R3 adds a fallback: when a filing has a filing agent's file name, use the prefix of the same company's latest ticker-form filing accepted before the formation, then follow dated name changes. A ticker is also now correct when it is any share class of the same company. Against DA006, the unresolved count per gold window falls from 143-359 to 88-240.

The fallback is less accurate than a filing's own prefix. In the gold windows it adds 87 to 115 correct names but 18 to 26 wrong ones, a hit rate near 80%. It matters most in 2021-2022, where it supplies about 35% of resolutions (1,625 of 4,505 resolved filers at 2021-12-31). So the error rate in those years is probably higher than the gold measure shows.

Limits

The rule was chosen after DA006's results on the same gold windows, so this is a development measure, not an independent one. Accuracy before 2024 is inferred from coverage. A replication should therefore treat a resolved symbol as confirmed only when it has traded bars at the formation and no other filer resolves to it. Historical counts include unlisted filers, which the replication's price and liquidity filters remove.

Next decision

Per the frozen stop rule, the next step is a frozen 2016-2024 DAG001 replication plan with sector-matched cells, reviewed by Expert before any price is read. Quarter-end prices for about 35 formations would be new Alpaca requests and need the owner's approval.
